# Security reports

For security-sensitive defects in Codex Red, use
[GitHub private vulnerability reporting](https://github.com/ssstrickys/codex-red/security/advisories/new)
when enabled for this repository. If that form is unavailable, confirm a private
maintainer-controlled channel before sharing sensitive information.
Reports can identify incorrect technical guidance or a packaging defect and its
affected reference/version. Use synthetic or redacted examples. Keep credentials,
customer evidence and unrelated sensitive targets out of public issues.

The skill supplies reference knowledge. It does not install analysis tools,
grant target authorization, create credentials, change Codex permissions or
override the host's governing instructions. The bundled scripts check package
structure and metadata; they do not execute analysis targets.

Package checks do not certify every technical statement, platform configuration
or possible input. Domain claims remain subject to current primary specifications
and the actual system behavior.
