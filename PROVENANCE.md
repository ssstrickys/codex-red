# Project authorship and source scope

Codex Red is a custom domain-reference skill for Codex. Its entry point,
reference organization, package checker, display assets and documentation are
maintained as part of this project.

The technical references draw on established specifications, public research
and credited third-party material. The underlying security principles are not
claimed as inventions of the project. Applicable MIT attribution remains in
[NOTICE.md](NOTICE.md) and [LICENSE.upstream.txt](LICENSE.upstream.txt).

Reference knowledge is conditional on the actual architecture, platform,
version and configuration. Source credit and package checks do not establish
universal expertise, exhaustive coverage or measured performance advantages.
Original project contributions use the [MIT License](LICENSE).
